## Shop Directory

ShopDirectory is a Minecraft Paper plugin that makes shopping on your server easy. Instead of visiting individual shops, on the hunt for a specific item, players can browse a searchable directory of everything currently for sale and teleport directly to the shop they want to visit.

Designed with simplicity in mind, ShopDirectory is great for both small and large servers.

## Features

- Browse every item currently for sale with /shops
- Search for specific items.
- View each player selling a selected item.
- Teleport directly to the shop you want to visit.
- Automatic refresh to the directory, keeping listings up to date.
- Supports any economy, including diamonds, emerald, and custom currencies.
- Fully customizable messages through ‘messages.yml’.
- Smart item indexing for fasting searching.
- Works with QuickShop and Shopkeepers.

## Requirements

Paper 1.21 or newer
Java 21 or newer
Quickshop and/or Shopkeepers 2.25.0 or newer.

## Commands

/shops

Open the shop browser.

/shops <item>

Search for a specific item and view players selling it.

/shops help

Display the help menu.

/shops version

Show the installed ShopDirectory version.

/shops reload

Reload the shop directory. (Admin only)

## Aliases

The alias /shopdirectory is also available.

Examples:

/shops
/shops diamond
/shops help
/shopdirectory version

## Configuration

ShopDirectory can be configured through config.yml.

Auto Refresh

auto-refresh-seconds: 300

By default, the shop directory refreshes every 300 seconds (5 minutes), to ensure players always see the most up to date items.

## Supported Plugins

- Shopkeepers
- Quickshop

## Installation

1. Install QuickShop, Shopkeepers, or both.
2. Download the latest version of ShopDirectory.
3. Place ShopDirectory.jar into your plugins folder.
4. Start or restart your server.
5. Create player shops using your supported shop plugin.
6. Run /shops to begin browsing everything for sale.
